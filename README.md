# منصة تسويق إلكتروني للسلع مع عمليات دفع وتوصيل
==========================

## ملخص المشروع
----------------

منصة تسويق إلكتروني للسلع مع عمليات دفع وتوصيل هي تطبيق إلكتروني يهدف إلى تسهيل عملية التسويق والبيع للسلع عبر الإنترنت، وتوفر عمليات دفع آمنة وتوصيل سريع.

## بنية المشروع
----------------

### مكونات المشروع

* `backend`: تطبيق الخادم المكتوب بلغة `Python` باستخدام `Flask` و `SQLAlchemy` لتعامل مع قاعدة البيانات.
* `frontend`: تطبيق العميل المكتوب بلغة `JavaScript` باستخدام `React` و `Redux` لتعامل مع البيانات.
* `docker-compose`: تطبيق لتشغيل البيئة باستخدام `docker-compose`.

### بنية قاعدة البيانات

* `users`: جدول يحتوي على معلومات المستخدمين.
* `products`: جدول يحتوي على معلومات المنتجات.
* `orders`: جدول يحتوي على معلومات الطلبات.
* `payments`: جدول يحتوي على معلومات العمليات الدفع.

### أدوار المستخدمين

* `admin`: دور يتيح الوصول إلى جميع الإجراءات.
* `seller`: دور يتيح الوصول إلى الإجراءات المتعلقة بالبيع.
* `buyer`: دور يتيح الوصول إلى الإجراءات المتعلقة بالشراء.

## إرشادات تشغيل البيئة باستخدام docker-compose
---------------------------------------------

1. تأكد من أنك تمتلك `docker` و `docker-compose` مثبتين على جهازك.
2. افتح مجلد المشروع في المتصفح.
3. افتح terminal واكتب الأمر `docker-compose up` لتشغيل البيئة.
4. افتح متصفحك واكتب `http://localhost:3000` لفتح التطبيق.

## مكونات المشروع
----------------

### backend

* `app.py`: تطبيق الخادم.
* `models.py`: تعريف جداول قاعدة البيانات.
* `routes.py`: تعريف إجراءات التطبيق.

### frontend

* `src`: مجلد يحتوي على المكونات الأساسية للتطبيق.
* `actions.js`: تعريف إجراءات التطبيق.
* `reducers.js`: تعريف إجراءات التطبيق.

### docker-compose

* `docker-compose.yml`: تعريف البيئة باستخدام `docker-compose`.
